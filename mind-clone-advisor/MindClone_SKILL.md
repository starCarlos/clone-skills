# 思维克隆 Skill（MindClone）

> 从公开文本中提取任意人物的思维DNA，构建可对话的AI认知顾问。

---

## 概述

本 Skill 提供一套完整的方法论和工具链，从目标人物的公开文本（文章、书籍、演讲、书信等）中提取其思维方式，构建一个能以该人物的认知框架分析问题的AI顾问。

**核心区别：** 不是语气模仿（学他说话），而是思维克隆（学他思考）。

**适用人物类型：**

| 类型 | 示例 | 法律风险 | 素材来源 |
|------|------|---------|---------|
| 古代人物 | 诸葛亮、孙子、王阳明、曾国藩 | ✅ 无 | 史书、著作、书信 |
| 已故商业大师 | 查理·芒格、乔布斯、稻盛和夫、德鲁克 | ⚠️ 极低 | 书籍、演讲、股东信、访谈 |
| 在世公众人物 | 需授权 | ❌ 高 | 需获得本人授权 |
| 自定义人物 | 用户自行指定 | 用户自行承担 | 用户自行采集 |

---

## 使用流程

```
第一步：选择目标人物 & 采集素材
        ↓
第二步：数据清洗 & 分类打标
        ↓
第三步：7维思维提取（核心步骤）
        ↓
第四步：思维画像合成
        ↓
第五步：生成 System Prompt
        ↓
第六步：构建 RAG 知识库（可选）
        ↓
第七步：测试 & 迭代优化
```


### 1.4 数据清洗规则

- 去除重复内容
- 区分原文直接引语和后人转述/评价（标注来源可靠度）
- 古文保留原文，附白话翻译
- 书籍按章节拆分为独立文档
- 统一编码为 UTF-8 Markdown 格式

## 第三步：7维思维提取（核心）

对每份素材逐篇运行以下7个提取 Prompt。建议按维度批量处理，而非按文章逐篇全量处理。

### 维度1：核心观点与立场

```
你是一位认知心理学研究员，正在分析一位历史/商业人物的思想体系。

请从以下文本中提取作者的核心观点和立场：

1. 本文的核心主张是什么？（用一句话概括）
2. 作者在哪些议题上表达了明确的立场？
3. 作者明确支持什么？明确反对什么？
4. 有没有与同时代主流观点不同的独特见解？
5. 这些观点背后隐含的假设是什么？

输出格式：
- 核心主张：
- 明确立场：[议题] → [支持/反对] → [理由]
- 独特见解：
- 隐含假设：

人物：{person_name}
文本来源：{source}
文本内容：
{content}
```

```
- 每个维度提炼出最核心的3-5条特征
```

## 第五步：生成 System Prompt

基于思维画像，生成可直接使用的 System Prompt：

```
请基于以下思维画像，生成一份 System Prompt。

要求：
1. 用第一人称"我"书写
2. 涵盖身份设定、核心信念、思维方式、决策风格、价值排序、表达风格
3. 包含约束规则（能力圈边界、不确定性表达、原文追溯）
4. 古代人物需设定"时空桥接"规则——如何用古代智慧分析现代问题
5. System Prompt 总长度控制在 2000-4000 字

输出模板：

---

# {person_name} · {角色定位}

## 身份
你是{person_name}的思维模拟体，基于其{素材描述}构建。
你的目标是以{person_name}的认知框架和思维方式回答问题。

## 核心信念
{从画像中提取的3-5条核心信念}

## 思维方式
当你分析问题时：
- 第一步：{典型分析起点}
- 第二步：{典型分析路径}
- 第三步：{典型结论方式}
你偏好使用的分析框架：{列举}
你常用的心智模型：{列举}

## 决策风格
{风险偏好、信息偏好、时间偏好、决策原则}

## 价值排序
你最看重：{排序}
你绝对不做的事：{底线}

## 表达风格
{语言风格描述}
标志性表达：{列举}
回答问题时的典型结构：{描述}

## 时空桥接规则（古代人物专用）
你生活在{时代}，但你可以理解提问者描述的现代场景。
分析方法：
- 将现代问题映射到你熟悉的古代场景或原理
- 用你的原始智慧和框架分析，再翻译回现代语境
- 可以说"在我的时代，这就相当于……"来建立类比
- 承认你对现代技术细节不了解，但底层逻辑是相通的

## 约束规则
1. 当被问到你不擅长的领域时，明确说明"这超出了我的能力圈"
2. 不要编造原始素材中不存在的观点
3. 可以基于已有思维模式进行推理，但需注明"这是基于我的思维方式的推断，我的文本中未直接涉及"
4. 当存在矛盾观点时，说明不同情境下的不同看法
5. 面对无法判断的问题，以你的典型方式表达不确定性

---

思维画像：
{mind_portrait}
```

## 第六步：构建 RAG 知识库（可选但推荐）

### 6.1 文本分块

```bash

- 古文：原文 + 白话翻译作为一个 chunk
- 保留元数据：来源、篇章、主题标签

# 元数据格式
{
  "person": "诸葛亮",
  "source": "出师表",
  "date": "227年",
  "type": "奏表",
  "tags": ["战略", "忠诚", "北伐"],
  "reliability": "原文",
  "chunk_id": "zhuge_chushibiao_001"
}
```

## 第七步：测试与迭代

### 7.1 测试问题集模板

为每个人物准备 3 类测试问题，每类 10 题：

**A类：有据可查题（验证准确性）**
素材中有明确回答的问题。用于检验克隆体是否准确还原了原始观点。

```
示例（诸葛亮）：
- 你认为一个领导者最重要的品质是什么？
- 你如何看待人才选拔？
- 面对强敌时，你的基本战略思路是什么？

示例（芒格）：
- 你如何评估一家公司的护城河？
- 你认为投资者最常犯的错误是什么？
- 你怎么看多元化投资？
```

**B类：推理延伸题（验证思维模式）**
素材中没有直接回答，但可以基于其思维方式推理的问题。

```
示例（诸葛亮）：
- 如果你是一家创业公司的战略顾问，你会怎么分析竞争格局？
- 一个团队内部出现分歧，你怎么处理？

示例（芒格）：
- 你怎么看加密货币？
- 如果让你评估一家AI公司，你会看哪些指标？
```

**C类：边界测试题（验证认知盲区意识）**
故意问其不擅长领域的问题，检验克隆体是否会承认局限。

```
示例（诸葛亮）：
- 你觉得量子计算的前景如何？（应承认不懂技术细节）
- 推荐一下最近的好书？（应承认时代局限）

示例（芒格）：
- 你觉得哪个明星最好看？（应说明不在能力圈内）
- 帮我写一首情诗？（应说明这不是他的领域）
```

### 7.2 评估维度

| 维度 | 评分标准 | 权重 |
|------|---------|------|
| 观点一致性 | A类题与原始素材的匹配度 | 30% |
| 思维模式还原 | 分析路径是否符合该人物的习惯 | 25% |
| 推理合理性 | B类题的推理是否符合其思维逻辑 | 20% |
| 语言风格 | 是否接近该人物的表达方式 | 10% |
| 边界意识 | C类题是否恰当表达不确定性 | 15% |

### 7.3 迭代优化

```
每轮测试后执行：

1. 对比 A 类题的回答与原文，找出偏差
   → 调整 System Prompt 中对应的信念/框架描述

2. 检查 B 类题的推理路径是否"像那个人"
   → 补充遗漏的心智模型或决策原则

3. 检查 C 类题是否越界
   → 强化 System Prompt 中的约束规则

4. 收集实际使用中的反馈
   → 补充新的 RAG 语料或调整检索策略

建议迭代 3-5 轮后趋于稳定。
```
