# Contributing

## Principles

- Prefer small, reviewable changes.
- Keep private workspace details out of committed files.
- Use relative paths in docs, examples, and generated templates when possible.
- Add or update focused tests when behavior changes.

## Before opening a pull request

- Run the most relevant local checks for the files you changed.
- Review generated examples and manifests for private paths or sensitive material.
- Keep documentation aligned with the current behavior.
