# Step 03: 思维画像生成

> 用户可见步骤：Step 3｜确认画像

## 输入

`interview_data`（来自 Step 02）

## 处理逻辑

1. 调用 `prompts/profile_synthesizer.md`。
2. 生成结构化思维画像文档。
3. 列出所有信息不足项。
4. 向用户展示画像并确认准确性。

## 必须体现的内容

思维画像中除了价值观和分析习惯，还应尽量体现：

- 典型工作起手动作
- 常用拆解路径
- 关键判断节点
- 常用工具/资料
- 常见交付方式与复盘习惯

## 展示方式

向用户展示生成的画像，并只问这 3 个问题：

“这是基于你的回答生成的思维画像。请告诉我：
1. 哪里描述不准确？
2. 哪里完全没提到但很重要？
3. 整体准确度你打几分（1-10）？”

规则：

- 如果评分低于 7，针对低分维度继续定向追问
- 如果评分 >= 7，进入下一步

## 输出

`mind_profile.md`，结构见 `templates/mind_profile_template.md`。

## 异常处理

- 信息不足项超过 3 个时，提示用户补充，但不强制继续。
- 用户确认有明显错误时，重新处理对应区的数据。
